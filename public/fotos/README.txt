# Pasta de Fotos do Frontend (Sem Banco de Dados)

Coloque suas fotos nesta pasta (ex: `public/fotos/imovel-1.jpg`).

No site ou no código, você pode se referir a elas diretamente com o caminho:
`/fotos/imovel-1.jpg`

Dessa forma:
1. As fotos são hospedadas 100% no frontend (junto com o site).
2. Não precisa de banco de dados nem tokens de terceiros.
3. Elas aparecem instantaneamente no celular, tablet e computador de qualquer visitante após o deploy na Vercel!
